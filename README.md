# 🧾 Staff Activity Reporter

A **frontend web application** that allows staff members to log, track, and review their daily tasks in a visually organized way.  
This project focuses on building an intuitive and clean interface using **HTML, CSS, and JavaScript** — no backend or database is used.

---

## 🚀 Project Overview

The **Staff Activity Reporter** helps users record their daily work activities such as teaching, meetings, research, and more.  
All data is stored **locally in the browser (LocalStorage)** so it stays even after page reloads — no server or login required.

You can try the live version here:  
👉 [Staff Activity Reporter - Live Demo](https://staff-activity-reporter-ciet.netlify.app)

---

## 🖼️ Features

✅ Add, view, edit, and delete activities  
✅ Store data in **LocalStorage** (no backend required)  
✅ Filter activities by **month, category, or status**  
✅ Display **activity summary cards** (Total Activities, Completed, Ongoing, etc.)  
✅ Clean and responsive UI that works on both desktop and mobile  
✅ Simple and fast — no page reloads
